# 창원시 버스 이동 공백 분석 및 누비다 DRT 시범 운영 제안

2026년 창원시 AI·데이터 활용 공모전 출품 프로젝트. 필수 제출물은 A4 10~20쪽 분석보고서와 참가신청서이고, 대시보드는 보고서 결과를 설명하는 보조 결과물이다.

## 폴더

| 경로 | 내용 |
|---|---|
| `data/raw/` | 원본 그대로(수정 금지). 출처·기준일은 `report/01_data_sources.md` |
| `data/processed/` | 스크립트가 만든 결과(검증표, 결과표). 손으로 고치지 않는다 |
| `scripts/` | `run_all.sh` 하나로 전체 재생성 |
| `dashboard/` | 정적 대시보드(예정). `data/processed` 결과만 읽는다 |
| `report/` | 보고서 원고와 근거 문서 |

## 재현

```bash
pip install -r requirements.txt
bash scripts/run_all.sh
```

## 원칙

- 시간표는 기점·종점 출발 시각만 쓴다. 첫차·막차·배차간격으로 중간 정류소 시각이나 대기시간을 만들지 않는다.
- 관측 결과(시간표 집계)와 가상 시나리오(DRT 제안)를 구분해 표기한다.
- 수요·예약 자료 없이 최적 차량 수나 대기시간 감소를 주장하지 않는다.
